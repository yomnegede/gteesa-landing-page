# GTEESA landing page

A static, responsive landing page for the Georgia Tech Eritrean-Ethiopian Student Association (GTEESA).

## Preview

Serve `dist/` with any static file server, for example `python3 -m http.server 4173 --directory dist`, then open `http://localhost:4173`.

## Updating the page

- Edit `dist/index.html` for copy, sections, events, and links.
- Edit `dist/styles.css` for the visual system and responsive layouts.
- Edit `dist/script.js` for the mobile menu and image viewer.
- The upcoming-events state intentionally contains no invented dates. Replace it only after verifying a new announcement from GTEESA.
- The general community GroupMe link was verified from GTEESA's [Linktree](https://linktr.ee/gteesa) on September 26, 2026.
